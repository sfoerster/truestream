# Changelog

## [0.1.0] - Unreleased

### Added
- Initial project scaffold
- WebRTC stream interception (RTC patch + element fallback)
- Local ONNX video inference worker (EfficientNet-B0)
- Local ONNX audio inference worker (RawNet2-lite)
- Five-level trust ladder state machine
- Ambient trust ring overlay (Shadow DOM)
- Side panel with score gauge, timeline, and verification CTA
- Vinsium bridge (stub)
- Cold path one-time verification link flow (stub)
- Model update system with manifest-based hot-swap
- Chrome CI and release workflows
